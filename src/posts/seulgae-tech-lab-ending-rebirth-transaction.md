호숫가 표지판에서 엔딩을 볼 수 있는지 확인하고 마지막 대화를 마치면 60초짜리 크레딧을 재생한다. 자격은 연구소장 직급과 지갑 잔액 10만 원 이상이다. 대화 도중 다른 화면에서 동전을 쓸 수 있으므로, 표지판을 처음 읽었을 때의 잔액만으로 완료를 처리할 수는 없었다.

## 조회와 완료의 책임을 나눈다

조회는 현재 자격과 기존 환생 여부를 알려 준다. 완료 요청은 트랜잭션 안에서 회원의 인벤토리 행을 잠근 뒤 잔액과 누적 업무 횟수를 읽는다. 직급은 기존 사원증과 같은 게임 규칙으로 계산한다. 통과한 요청은 회원의 `reborn`을 `true`로 기록한다. 이미 기록된 경우 조건부 UPDATE가 같은 값을 다시 쓰지 않는다. 환생은 엔딩을 마쳤다는 표시이며 지갑을 차감하거나 계정을 초기화하지 않는다.

## 스키마를 준비하고 기능을 연결한다

PR #125는 환생 표시 컬럼을 추가하고 V24·V25를 지원하는 릴리스를 준비했다. 오락 연구실 명칭에 맞게 안내와 프런트 테스트 기대값도 갱신했다. 표지판과 엔딩 영상, 완료 API를 연결한 #126의 릴리스는 V25를 요구한다. 두 PR의 병합과 #126의 백엔드·프런트엔드·운영 도구 CI 통과를 확인했다. PR에는 일회용 PostgreSQL에서 직급·잔액 경계와 중복 완료를 검증하는 내용이 기록돼 있다. 운영 DB와 실제 영상 재생은 이번에 별도로 확인하지 않았다.
