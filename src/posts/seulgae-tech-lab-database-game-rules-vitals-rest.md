행동 비용과 간식 가격이 서버와 화면의 상수에 각각 있으면 같은 규칙을 고칠 때 표시와 실제 처리가 달라질 수 있다. PR #120·#121은 HP·기력 관련 규칙을 테이블로 옮겼고, #123·#124는 그 규칙을 새 행동과 휴식에 확장했다.

## 규칙의 출처를 공유한다

V23은 행동 비용, 간식과 직급 규칙을 준비했다. 서버 `GameRules`는 값을 읽어 1분간 캐시하고, 읽기 실패나 필수 직급 누락 시 이전 값 또는 초기 기본값을 사용한다. API는 화면에도 규칙 값을 제공해 가격과 비용 안내를 같은 출처로 만든다. 캐시가 있으므로 DB 수정이 즉시 모든 화면에 반영된다고 가정할 수는 없다.

운영 도서관에는 규칙 테이블과 변경 시 주의 사항을 기록했다. 일일 한도나 확률 등 당시 여전히 코드에 남은 값도 있어 모든 게임 규칙이 DB로 이동한 것은 아니다.

## 행동과 차감을 같은 거래로

V24는 낚시, 내기, Java 답 제출, 주식 거래와 가구 배치에 행동 비용을 추가했다. `VitalsGate`는 행동 전 자원을 확인하고 같은 트랜잭션에서 차감한다. 부족할 때 동전이나 물건이 바뀌지 않도록 각 호출 경로의 원자성을 테스트하는 것이 중요하다.

침대 휴식은 배치된 침대가 있는지 확인하고 마지막 휴식 시각을 조건부 UPDATE해 회복 간격을 제한한다. 여러 탭이 동시에 요청하더라도 같은 간격의 회복을 중복 적용하지 않으려는 설계다.

PR #124에는 백엔드 테스트와 프런트 169개 테스트, 타입 검사 통과 및 대체 없는 로컬 규칙 API 확인이 기록됐다. 실제 침대 화면은 로그인 제약으로 당시 직접 확인하지 못했다. 운영 도서관과 생활 가이드는 설정을 이해하는 도구이며 운영 반영 성공 자체를 증명하지는 않는다.
