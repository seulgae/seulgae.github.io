서버실 랙에서 상태를 보여 주는 기능에 이어, 공간을 순찰하는 로봇 다섯이 서버 점검 방법을 안내하게 됐다. PR #90은 운영 지표를 수집하는 코드와 게임 속 설명을 연결하는 역할을 맡는다.

## 순찰 경로와 실제 장비를 분리한다

로봇은 온도·팬·백업·로그·보안을 주제로 말하며 랙과 장비를 피하는 경로를 돈다. 이 대사는 게임 연출이다. 예를 들어 로봇의 온도 관련 대사를 실제 센서가 측정한 값으로 해석해서는 안 된다.

로봇 근처에서 상호작용하면 안내 패널이 열리고 MINA SSHD, EXEC 채널과 수집 주기, 키·호스트 검증의 개념을 짧게 보여 준다. 자세한 설명은 기존 서버 점검 글로 연결한다. 방 연출에서 패널을 여는 동작을 장면의 입력 잠금·효과음과 이어 사용자가 게임 안에서 설명을 볼 수 있게 했다.

PR 기록에는 로봇 경로와 텍스처·링크를 검사한 프런트 테스트 151개, 타입 검사와 빌드 통과가 남아 있다. 로컬 화면에서 순찰과 안내 창을 확인했지만, 패널은 E키 입력 대신 같은 열기 이벤트로 확인했다. 두 검증 범위는 구분해야 한다.
